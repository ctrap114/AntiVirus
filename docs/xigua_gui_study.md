# XIGUASecurity GUI 学习笔记

> 目的：分析 `D:\XIGUASecurity`（XIGUASecurity 10x）的界面设计与交互组织，
> 为 Everbloom Security 的 WinUI 3 GUI 演进提供可借鉴的清单。本文只做设计层面的
> 学习与记录，不复制其代码或资源。

## 1. 技术形态

通过窗口枚举（Win32 `EnumWindows`）确认：

| 项目 | 结论 |
|---|---|
| 应用框架 | Tauri 2.x（`Tauri Window` 窗口类 + `WRY_WEBVIEW` + WebView2 渲染进程） |
| 主窗口 | 单主窗口，页面标题 "Antivirus Security"，前端为 HTML/CSS/JS |
| 弹窗策略 | 实时拦截、沙箱行为监控各自使用独立 Tauri 窗口，而不是主窗口内嵌页 |
| 托盘 | `tray_icon_app` 原生托盘窗口 |
| UAC 辅助 | 自定义窗口类 `com.memz-uac.xiguasecurity-sic/siw` 用于提权流程 |
| 驱动兼容性提示 | 原生 `#32770` 对话框：进程拦截驱动在 Windows 10 上可能存在兼容性问题，
  询问用户是否启用，并提供"基础防护"降级路径 |

从二进制中提取到的前端字符串（UTF-8 中文资源）显示其主要导航为：
**扫描 / 实时监控 / 行为防护 / 驱动防护 / 更新 / 隔离区 / 系统 / 日志 / 其他**。

## 2. 值得 Everbloom Security 借鉴的设计点

### 2.1 交互层

1. **独立的实时拦截对话框**：检测到威胁时弹出独立置顶窗口，展示行为摘要、
   路径、评分与"用户决策"按钮（允许/阻止/隔离）。Everbloom Security 目前只有托盘通知，
   缺少可交互的拦截弹窗；可在 WinUI 中新增 `ThreatDialog` 页面并复用现有 IPC。
2. **沙箱行为监控窗口**：包含"行为链拓扑""行为链时间线""最近活动详情"三个视图。
   Everbloom Security 的 Threat Management 已有 Mermaid 行为链雏形，可以按
   拓扑图 + 时间线 + 明细列表三视图拆分呈现。
3. **防护时间线**：把实时监控事件按时间轴展示（"防护时间线"），比纯表格更直观。
4. **桌宠彩蛋**：XIGUA 有"洛天依桌宠"。Everbloom Security 的品牌是猫娘，做一个
   可开关的猫娘桌宠（托盘菜单入口）成本低且契合品牌。
5. **驱动功能灰度启用**：对可能引发兼容性问题的内核能力先弹窗说明风险，
   并提供用户态降级方案。Everbloom Security 未来引入 Minifilter 时应采用同样的模式。

### 2.2 功能层

6. **感染修复（disinfection）**：字符串中出现完整的清毒流程——识别感染型病毒、
   定位恶意节区、恢复原始入口点、保存修复后文件。Everbloom Security 只有隔离/删除，
   可作为远期功能立项。
7. **云端沙箱 + 多引擎查询**：上传样本 → 查缓存报告 → 轮询结果 → 多引擎聚合。
   报告缓存命中时跳过上传。Everbloom Security 的 cloud 层目前是占位 no-op，
   该"上传-查询-缓存"状态机值得抄作业（仍需保持本地裁决优先）。
8. **中文环境误报治理**：内置常见国产软件名单（百度网盘、腾讯会议、向日葵、
   王牌输入法、夸克网盘等）用于降噪；同时维护竞品 AV 进程名列表
   （火绒、金山、卡巴、诺顿、小红伞等）用于识别"杀软对抗（AVKill）"行为。
9. **本土威胁情报**：针对银狐木马有专门特征（随机文件名特征、传播链）、
   辅助功能后门（sethc.exe 粘滞键劫持）、仿冒知名软件名检测。
10. **系统篡改信号目录**：大量"XX被禁用"字符串构成勒索/锁机行为的启发式来源：
    任务管理器、注册表编辑器、控制面板、命令提示符、文件夹选项、系统还原、
    注销/关机选项、快速用户切换、磁盘驱动器隐藏、桌面图标隐藏等。
    这份清单可以直接转成 Everbloom Security `heuristic.rs` 的新静态规则族。

### 2.3 工程层

11. **规则热更新带备份回滚**："备份当前规则""替换规则数据库""重新加载规则"。
    Everbloom Security 已有数据库热重载回滚，但 YARA 规则目录还没有同样的备份机制。
12. **诊断日志分级上传**：日志上传器 + 心跳 + 分块下载更新器，UI 文案区分
    "下载中/下载完成准备安装"。Everbloom Security Updates 页可补充进度阶段文案。
13. **前端资产嵌入主程序**（Tauri 单 exe）：Everbloom Security 的 WinUI 打包已经类似，
    保持单文件分发是正确方向。

## 3. 与 Everbloom Security 现状的差距对照

| 能力 | XIGUASecurity | Everbloom Security | 行动建议 |
|---|---|---|---|
| 实时拦截弹窗 | 独立窗口+用户决策 | 仅托盘通知 | 新增 ThreatDialog |
| 行为链可视化 | 拓扑/时间线/明细 | Mermaid 模板 | 三视图改造 |
| 云端沙箱 | 上传/轮询/缓存 | 占位 | 设计状态机，保持本地优先 |
| 感染修复 | 有 | 无 | 远期立项 |
| 桌宠 | 有 | 无 | 低成本品牌功能 |
| 驱动兼容灰度 | 弹窗+降级 | 未实现驱动 | Minifilter 设计时采纳 |
| 国产软件降噪 | 名单化 | 部分 builtin 进程 | 扩充 allowlist 词表 |
| 系统篡改启发式 | 大量规则 | 少量 | 转化为静态规则 |

## 4. 方法论备注

- 窗口结构：PowerShell P/Invoke `EnumWindows/EnumChildWindows` +
  `GetClassName/GetWindowText`，输出 UTF-8 文件避免控制台乱码。
- 字符串资源：对 PE 做整文件 `utf-8` 解码后用 CJK 正则提取（581 条有效）；
  `utf-16le` 解码噪声过大（8.4 万条），仅作辅助交叉验证。
- 截图方案因当前模型不支持图像输入而放弃视觉走查，全部结论来自
  结构枚举与字符串证据，未反编译、未修改目标程序。
