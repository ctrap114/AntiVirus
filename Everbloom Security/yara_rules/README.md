# YARA Rules Directory

This directory contains extracted YARA rules from `yaraify-rules.zip`.

Location of extracted rules:
- `everbloom/yara_rules/yaraify_rules/`

Number of rule files: 557

Usage:
- Point your YARA engine or `yara_rules_path` configuration to this directory.
- The engine will recursively read `.yar`/`.yara` files from the directory.

Notes:
- These rules were extracted from the `yaraify-rules.zip` archive located in the repository root.
- Keep the directory under version control if you want the rules packaged with the project.
